# Repository Instructions

## Privacy

- This is a personal configuration repository.
- Never commit credentials, tokens, private keys, or other secrets.
- Review every collected file before committing it.

## Structure

- Keep `dotfiles.json` as the single source of truth.
- Store collected machine files only under `configs/` through `dtf` [commands](https://github.com/dev0xffh/dtf).
- Keep `AGENTS.md` and `CLAUDE.md` byte-for-byte identical.

## Git

- Keep commit messages short and clear.
